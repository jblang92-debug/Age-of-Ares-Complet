# Age of Ares — Complet

Version étendue d'Age of Ares : progression d'âges dans la même partie,
de l'Antiquité jusqu'à l'âge galactique (cavalerie, sièges, flottes...).

Projet indépendant de la première version (dépôt Age-of-Ares), qui reste intacte.

Jouer : https://jblang92-debug.github.io/Age-of-Ares-Complet/

Code source : dossier `game/` (Vite + Three.js). `cd game && npm ci && npx vite build`, puis copier `game/dist/*` à la racine.
